🎨 assets

Shared static assets. Consume via the assets git submodule.

  • img/ — images, sprites, icons, logos
  • audio/ — music / long-form audio
  • sound/ — short sound effects
  • fonts/ — webfonts
  • css/ — stylesheets and themes
  • html/ — HTML partials
  • tokens/ — design tokens
